# OpenLabs3D rack collection

Nine 1024 × 1024 transparent PNGs rendered with Blender 4.5.3 / Cycles (48 samples, denoising, AgX). Generated by `scripts/render_racks.py` using actual meshes and Boolean tube openings, bevelled decks and structural end walls. No image-generation model, flat SVG, CSS recoloring or paid service is used.

Run `blender -b -t 6 --python scripts/render_racks.py` from any directory. The script writes here. Each geometry uses fixed camera, framing and studio lighting for Aqua blue (`aqua-blue`), Signal red (`signal-red`) and Cream (`cream`). These are all color options from the existing website.

- `microtube-rack/`: 24 openings, nominal 11 mm diameter.
- `15ml-rack/`: 12 openings, nominal 17 mm diameter.
- `50ml-rack/`: 6 openings, nominal 30 mm diameter.

These are concept geometries, not validated manufacturing designs. Tube dimensions, fit, print tolerances, material performance and laboratory suitability have not been tested.

`app.seed_collection` inserts only absent collection keys. Uploaded user images and existing listings/orders are never replaced. The old demonstration catalogue was JavaScript/localStorage data, not database records. Legacy browser-local orders remain intact.
