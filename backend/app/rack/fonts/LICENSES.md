# Bundled fonts

Used to draw label letters into custom rack geometry. Both licences allow embedding and use in products.

|---|---|---|
| LiberationSans-Bold.ttf | Liberation Sans Bold (Red Hat, Arimo by Google) | SIL Open Font License 1.1 |
| DejaVuSerif-Bold.ttf, DejaVuSansMono-Bold.ttf | DejaVu Fonts | Bitstream Vera licence with DejaVu changes (free for any use; do not sell the fonts alone) |

Full texts: https://github.com/liberationfonts/liberation-fonts/blob/main/LICENSE and https://dejavu-fonts.github.io/License.html
